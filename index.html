First-Time Token Setup

Encrypt your GitHub Personal Access Token with a password. The encrypted token will be stored on your GitHub repo.

Required on first setup. Lets you re-open Setup to change your token or password.

Instructions:

  1. Enter your GitHub Personal Access Token (starts with ghp_...)
  2. Choose a Login Password — this is what you'll use to unlock the app
  3. Choose a Setup Protection Password — this lets you re-open Setup later
  4. Click "Encrypt Token" — your token gets encrypted and uploaded to GitHub as a .token file

Note: Your raw token is NEVER stored anywhere. Only the AES-256-GCM encrypted version lives on GitHub.
